# Pulse Icon Pack

Local SVG icon pack used by GLPI BrandPulse counters.

Use an icon in counter JSON with the `pulse:name` syntax, for example:

```json
"icon": "pulse:tasks"
```

Available icons:

- `pulse:tasks`
- `pulse:waiting`
- `pulse:medical`
- `pulse:ticket`
- `pulse:it`
- `pulse:unassigned`
- `pulse:bell`
- `pulse:clock`
- `pulse:warning`
- `pulse:validation`
- `pulse:asset`
- `pulse:brand`
- `pulse:search`

These SVGs are local project assets and do not require a third-party icon service.
